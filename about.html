About Vapor

Simple, accurate, open-source vaping calculators.

Vapor is a free static website that provides lightweight tools for common vaping calculations. The first release includes an e-liquid mixing calculator and an Ohm's law calculator.

Principles

  • No backend, no database, and no external APIs.
  • No accounts and no tracking.
  • No runtime dependencies and no required build step.
  • All math runs locally in your browser.
  • Preferences stay on your device via local storage.

Technology

The site is built with semantic HTML, modern CSS, and vanilla JavaScript ES modules. It can be served by any static file host, including GitHub Pages.

Contributing

Contributions are welcome. See CONTRIBUTING.md for guidelines, and review the disclaimer before using the calculators.
